# Todo App

A local-first task planning and scheduling app.

Initial product direction:

- macOS desktop first.
- Tauri 2 shell with a TypeScript frontend.
- Rust core for tasks, scheduling, sync, and provider abstractions.
- SQLite local storage.
- Optional TaskNotes sync.
- Optional calendar sync.
- Optional bring-your-own LLM support for OpenAI, Anthropic, and Ollama.

See [docs/architecture.md](docs/architecture.md) for the current architecture notes.
